# CrudCloud Frontend

Plataforma de gestión de bases de datos en la nube - Frontend desarrollado con React + TypeScript + Vite + Tailwind CSS.

## 🚀 Características

- Landing Page moderna y responsive
- Diseño con Tailwind CSS (sin Bootstrap)
- TypeScript para type safety
- Componentes reutilizables
- Estructura de carpetas escalable

## 📁 Estructura del Proyecto

```
src/
├── components/
│   ├── common/          # Componentes reutilizables (Button, Card, etc.)
│   ├── layout/          # Header, Footer
│   └── landing/         # Secciones de la landing page
├── pages/               # Páginas principales
├── constants/           # Constantes (planes, features, etc.)
├── types/               # TypeScript interfaces
└── styles/              # CSS global
```

## 🛠️ Tecnologías

- **React 19.2** - Librería UI
- **TypeScript** - Type safety
- **Vite** - Build tool
- **Tailwind CSS** - Estilos
- **PostCSS** - Procesamiento CSS

## 📦 Instalación

```bash
npm install
```

## 🏃 Desarrollo

```bash
npm run dev
```

## 🏗️ Build

```bash
npm run build
```

## 📝 Convenciones

- **Conventional Commits** para mensajes de commit
- **Componentes funcionales** con TypeScript
- **CSS Modules** cuando sea necesario
- **Props typing** obligatorio
